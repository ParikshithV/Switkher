# Switkher website

The Switkher landing page is built with [Astro](https://astro.build/) and deployed to Cloudflare.

From this directory, install dependencies and start the development server:

```sh
npm install
npm run dev
```

Use `npm run build` to create a production build, `npm run preview` to preview it with Wrangler, and `npm run deploy` to deploy it. Deployment requires the configured Cloudflare account.

For information about the Switkher macOS app, see the [project README](../README.md).
